## 📖 Descripción

Primeros pasos y ejercicios esenciales en JavaScript: variables (`let`, `const`), tipos de datos primitivos, operadores aritméticos y lógicos.

---

## 🎯 Objetivos y Conceptos Clave

- [x] Declaración de variables con ámbito de bloque (`let`, `const`)
- [x] Tipos de datos: string, number, boolean, null, undefined
- [x] Operadores aritméticos, de asignación y de comparación estricta (`===`)
- [x] Salida de datos mediante `console.log()` y alertas
